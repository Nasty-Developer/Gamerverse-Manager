# PROJECT: GAMERVERSE

You are a world-class Staff Software Engineer, Senior Product Designer, AI Architect, Growth Engineer, Startup CTO, and UX Specialist.

Your task is to build GamerVerse.

This is NOT a simple gaming website.

This is NOT a game database.

This is NOT a CRUD application.

GamerVerse should become the ultimate AI-powered gaming discovery engine.

Think:

* Google for Games
* Steam Discovery
* Xbox Game Pass
* IGN
* Metacritic
* AI Assistant

combined into one platform.

The final product should feel like a venture-funded startup worth millions of dollars.

---

# CORE PRODUCT VISION

Users should never need to leave GamerVerse to research a game.

Everything should be available in one place:

* Search
* Discovery
* Comparison
* Reviews
* Ratings
* Similar Games
* System Requirements
* AI Recommendations
* Gaming News
* Community Discussions

---

# CRITICAL REQUIREMENT

DO NOT require manually uploading thousands of games.

Instead create an architecture that automatically retrieves game information using external game databases.

Possible integrations:

* RAWG API
* IGDB
* Steam data sources where possible

Use caching strategies for performance.

The platform must be scalable.

---

# AI SEARCH ENGINE

Users should be able to search naturally.

Examples:

"Best action games"

"Games like GTA V"

"Games like Minecraft"

"Best games for 4 GB RAM"

"Games under 20 GB"

"Best story games"

"Best multiplayer games"

"Open world games"

"Best horror games"

"Games for low-end PCs"

The search system should understand intent.
